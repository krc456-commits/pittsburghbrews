# Pittsburgh Brews image policy

Every production image must have a documented source and a clear reuse basis.

## Allowed sources

- Original photos owned by Pittsburgh Brews.
- Creative Commons or public-domain images with license terms recorded and attribution shown when required.
- Brewery media-kit assets only when the brewery's published terms allow the intended use.
- Brewery-provided photos or logos when Pittsburgh Brews has explicit permission to use them.
- Stock imagery with a license that clearly permits the intended website use.

## Not allowed by default

- Images copied from Google Images, Google Maps, Yelp, Facebook, Instagram, Untappd, or other social/review platforms.
- Brewery website images with no reuse permission stated.
- Logos pulled from search results or third-party logo sites without a clear usage basis.
- User-uploaded photos unless the photographer grants the needed rights.

## Required metadata

For each production image, record:

- image URL or local asset path
- descriptive alt text
- source label
- source URL
- license or permission basis
- license URL when applicable
- photographer/creator credit when required

When rights are unclear, use the built-in placeholder instead of the image.
